PHP libraries for HTML elements, form fields, and form models.

Build markup and connect form controls to application data through explicit
PHP APIs.

Read each repository's installation and compatibility notes before choosing a
version.

## Documentation and contribution

Start with each repository's README, or explore the
[independent documentation portal](https://yii2-framework.github.io/docs/).

Read the
[contribution guide](https://github.com/ui-awesome/.github/blob/main/CONTRIBUTING.md)
before proposing a change. For security concerns, follow the
[security policy](https://github.com/ui-awesome/.github/blob/main/SECURITY.md).
