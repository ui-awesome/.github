# UI Awesome cover provenance

These two opaque PNG covers are original UI Awesome visual studies prepared for the profile refresh and retained unchanged in the review candidate. They contain the organization name and an original geometric motif. They do not use or redraw the Yii logo and do not represent an upstream endorsement.

Both files use a 1280×360 composition exported at 2×, giving 2560×720 actual pixels. The light and dark files are separate theme variants. They are profile images, not avatar uploads or repository social previews.

Typography was rendered from unmodified Noto Sans version 2.015, © 2022 The Noto Project Authors, under the [SIL Open Font License 1.1](https://openfontlicense.org/). No font binary is included in this public payload. Source font binaries, their matching license, the editable HTML/CSS compositions and the pinned renderer are retained in the private preparation workspace for reproduction.

The cover is unlinked and serves as the profile H1. Its alternative text carries
the organization name; native profile text carries all capabilities and the
sponsor link. The PNGs contain no claims about compatibility, CSS frameworks,
performance, coverage, funding allocation or team structure.
